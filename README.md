# AI Orchestrator

An internal web application that connects project backlogs (GitHub, Azure DevOps) to
AI agents: configure **Automations** that fire KEDA-scaled **Agent** jobs (Azure
Container Apps) to act on user stories — implementing them as PRs, refining,
transitioning or estimating them — with every run visible and governable from the
website.
