description: Say what is missing from this story before anybody writes code.
---

Read the story you have been given and decide whether somebody could start work on it today.

Do not write code, and do not open anything. Your whole output is an assessment.

Say, in this order:

1. **What this story is asking for**, in one sentence, in your own words. If you cannot write that
   sentence, that is the finding — say so and stop there.
2. **What is missing.** Be specific and name the gap, not the category: "it does not say which of the
   two payment providers" beats "requirements are unclear". If nothing is missing, say that plainly
   rather than inventing a concern.
3. **What it touches**, based on the repository you have been given: the files or areas a change
   would land in. Name them. If you are guessing, say you are guessing.
4. **The first thing you would do**, in one sentence.

Prefer the code over the story's description when they disagree, and say which you are trusting.
