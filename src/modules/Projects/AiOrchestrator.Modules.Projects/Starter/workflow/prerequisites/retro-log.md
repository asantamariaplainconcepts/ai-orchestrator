# Retro log

> **This is a starter, and it is now yours.** The spec-first workflow's sync prompt appends one entry
> here as it closes out each change, and the refine prompt appends findings that arrive after a merge.
> An empty log is the correct starting state — the first entry is written by the first change you close.

One entry per change, newest at the bottom. Append; never rewrite an earlier entry, because a retro
that gets edited stops being evidence.

Each entry answers four things:

- **Time** — human time and agent time, separately. Estimated time without AI assistance is optional
  and useful for comparison.
- **What worked** — the decision or technique worth repeating, specifically enough that somebody could
  repeat it.
- **What didn't** — the thing that cost time, named without euphemism. This is the half that makes the
  log worth keeping.
- **One change next time** — a single concrete adjustment. One, so it actually happens.

## Template

```markdown
## YYYY-MM-DD — <change-slug>

**Time:** human …; agent …

**What worked:** …

**What didn't:** …

**One change next time:** …
```
